# Hiba's Code Arena 💜

منصة تعليمية تفاعلية باللغة العربية، مخصصة للمعلمة هبة. تعرّف الطالبات بأساسيات Python عبر اختبارات قصيرة وتحديات تصحيح أخطاء، مع نظام نقاط وشارات لمتابعة التقدم.

## المزايا

- واجهة عربية باتجاه من اليمين إلى اليسار، بتصميم داكن وتدرجات بنفسجية وزرقاء ومتجاوبة.
- 15 سؤال اختيار من متعدد، موزعة على مستويات مبتدئ ومتوسط ومحترف، مع أربعة خيارات وشرح للإجابة.
- أربعة تحديات عملية لتشخيص أخطاء Python وتصحيحها.
- نقاط: 10 نقاط لكل إجابة صحيحة و20 نقطة لكل تحدٍ محلول بشكل صحيح.
- صفحة إنجازات تعرض التقدم والشارات.
- رسالة إهداء خاصة إلى المعلمة هبة وصفحة تشرح المشروع وتقنياته.
- جميع التفاعلات تعمل داخل جلسة Streamlit؛ لا حاجة إلى قاعدة بيانات أو إعدادات إضافية.

## المتطلبات

- Python 3.9 أو أحدث.
- اتصال بالإنترنت عند التثبيت، وكذلك لتحميل خط Cairo من Google Fonts (إن لم يتوفر محلياً، سيستخدم المتصفح خطاً احتياطياً).

## التشغيل محلياً

افتح Terminal في مجلد المشروع ثم نفّذ:

```bash
python -m venv .venv
```

فعّل البيئة الافتراضية:

**Windows (PowerShell):**

```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

ثبّت الاعتماديات وشغّل التطبيق:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

افتح الرابط الذي يظهر في الطرفية (غالباً http://localhost:8501). لإيقاف التطبيق اضغط `Ctrl+C` في الطرفية.

## ملاحظات

- النقاط والإجابات والإنجازات تبقى محفوظة طوال جلسة التطبيق الحالية، وتُعاد عند انتهاء الجلسة أو إعادة تشغيل التطبيق.
- يمكن تشغيل المشروع في GitHub Codespaces بالطريقة نفسها من طرفية Codespace؛ استخدم رابط المنفذ 8501 الذي يعرضه Codespaces.
